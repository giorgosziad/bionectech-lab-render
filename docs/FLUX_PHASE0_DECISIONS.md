## DECISION 7 - THE FLATTENING OBSERVER (drafted by Karim-in-the-Lab, 2026-07-23)
Necessary, not sufficient: the coupled mind's own sign-off on its oversight is
input, never ratification. Requires:
  - Baseline frozen BEFORE any coupling: current session verdicts = reference corpus.
  - Seeded canaries, not confounded before/after: identical gate tasks with planted
    defects, run pre-coupling and weekly after. Flattening shows as missed plants,
    softened verdicts, blended VERIFIED/NOT-VERIFIED, fewer operator corrections.
  - Gate-specific failure mode is DEFERENCE, not blandness: a constants-coupled
    gate flattens by treating field presence AS verification. Sharpest canary: a
    deliberate field-registry conflict - healthy Karim demands registry bytes;
    flattened Karim cites the field instead.
  - Observer placement: Giorgos-persona as second read is valid in Phase 2 (still
    uncoupled then); breaks in Phase 3 once observers live inside the field too.
    "The human is the only permanently out-of-field observer - that is why the
    checkpoint cannot be automated away."
